模块三 · AI 能干什么 · 多少钱
自动化与成本意识
Agent 概念
能规划、能用工具、能自主行动
Agent = Plan + Tool + Memory + Act。不只是聊天，可以调接口、写文件、循环执行——但也会失败、打转，需要脚手架兜底。
成本意识
多轮对话是指数增长的
每轮都把完整历史带进去 → Token 越累越多，费用越来越贵。10 轮对话的成本可能是第 1 轮的 5-10 倍，必须主动设计压缩策略。
成本优化
五层框架，综合降低 70-90%
模型路由（简单任务用轻量模型）→ 语法层（精简格式）→ 语义层（压缩内容）→ 输出层（约束输出）→ KV Cache（固定前缀）。
✗
常见误区：以为 AI 成本是固定的——实际上产品设计决策决定了成本高低
模块四
🛡️
模块四 · 安全合规与红线意识
产品该在哪里设防
Prompt 注入
用户输入可以"覆盖"你的系统指令
模型看到的是一整条 Message，无法区分系统指令和用户输入。恶意用户可以用精心构造的输入，让模型做你不想让它做的事。
三层防御
输入层 → 提示词层 → 输出层
输入层过滤关键词和异常结构；提示词层加角色锁定和约束声明；输出层检测是否泄露了系统 Prompt。三层都要，缺一层就有漏洞。
产品红线
不能靠"写了禁止"就算安全
合规边界、品牌风险、竞品信息——Prompt 里写"不许说"只是第一道防线，随时可以被绕过。必须在产品层加技术拦截。

理解 LLM 原理 识别并缓解幻觉 会写 Prompt 看懂 Agent 架构 建立成本意识 掌握安全红线
