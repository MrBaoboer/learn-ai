Agent 工程

MCP 協議：工具的 USB 介面

USB 之前每臺裝置要專屬資料線；MCP 之前每個 Agent 要專屬對接程式碼。

一句話速覽

stdio / SSE / Streamable HTTP 三種傳輸方式對比，資料流動畫

Before / After 對比
Before 沒有 MCP 的世界
9 條專屬對接
新增 1 個工具 → +3 條對接
After 有 MCP 的世界
6 條標準連線
新增 1 個工具 → 只需 +1 條適配
三種傳輸方式 · 點選查看資料流動
stdio 本地程序
Agent 啟動一個本地程式，通過標準輸入輸出通訊
SSE 伺服器推送
Agent 透過 HTTP 連線遠端服務，伺服器主動推送資料
Streamable HTTP 雙向流
最新標準，支援雙向流式通訊
Takeaway
Takeaway　MCP 就是 AI 工具的 USB 標準：工具開發者只寫一次適配，就能接入所有 Agent。沒有 MCP 之前，每個 Agent 都要為每個工具寫專屬對接程式碼，就像每臺裝置都要專屬資料線一樣。
