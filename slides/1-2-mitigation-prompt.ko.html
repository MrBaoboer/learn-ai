제약 없는 Prompt
제약 있는 System Prompt
System Prompt 템플릿 · 바로 재사용 가능

        

      


      
      

        

          
          
          
          예시: 「양자 얽힘의 2025년 상업적 응용」
        

        

          
모델에 전송되는 내용:

          

          
모델 응답:

          

        

      


      
      

        

          

            
System Prompt 없음

            

              사용자 질문
              →
              날조된 답변…
            

            
모델이 학습 기억을 바탕으로 직접 Token을 예측하며, 지식 공백을 만나면 유창하게 날조합니다.

          

          

          

            
제약 있는 System Prompt 추가

            

              사용자 질문
              +
              불확실하면
              모른다고 말하세요
              →
              잘 모르겠습니다…
            

            
파란색 제약어가 컨텍스트의 일부가 되어 「모른다고 인정」하는 시퀀스의 확률을 높입니다.

          

        

        

          

            모델이 다음 Token을 예측할 때, 현재 컨텍스트의 모든 Token이 확률 분포에 영향을 줍니다.
            System Prompt에 주입된 제약어는 컨텍스트에 「고품질 선행 텍스트」를 배치하는 것입니다:
            이는 「잘 모르겠습니다」 시퀀스의 확률을 높이고, 날조 시퀀스의 확률을 낮춥니다.
            본질: 정밀하게 설계된 선행 텍스트로 후속 출력의 확률 분포를 정향 조작합니다.
          

        

        

          
⚠ 한계: 모델은 자신이 모른다는 것을 모릅니다

          

            

              
제약 지시가 효과적인 전제

              

                모델이 특정 질문에 대해 어느 정도 불확실함을 느낄 때, 제약어가 모른다고 인정하는 시퀀스로 유도할 수 있습니다.

                → 적합: 지식 범위 초과 질문, 모호한 질의, 시효성 정보
              

            

            

            

              
제약 지시가 실패하는 상황

              

                모델이 잘못된 답변에 매우 자신 있을 때, 첫 번째 후보 Token이 이미 틀리므로 제약어로는 그 확률을 바꿀 수 없습니다.

                → 실패: 학습 데이터의 시스템적 오류, 사실로 취급되는 구식 지식
              

            

            

            

              
PM 대응 전략

              

                「모델이 자신 있지만 틀릴 수 있는」 영역에서는 Prompt 제약만으로는 부족합니다.

                → RAG (실제 지식 주입) 또는 인간 검토 최후 방어선과 결합 필요
