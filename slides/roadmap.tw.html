第二步 · 看看這條路覆蓋哪裡

實線高亮的整章都要學，虛線的這一章只挑了一部分（後面標著挑了幾節），變淡的是這條路明確建議跳過的。那些內容本身沒問題，你的目標用不上而已。

為什麼這麼劃

「只想會用」跳過全部原理和工程內容，只學怎麼把 AI 用對：它在幹什麼、為什麼會編、怎麼問才問得出東西、什麼能放心交給它。除了零基礎入門篇，Harness 核心篇的上下文工程、Prompt 工程、實用技巧這三個主題也在裡面；協作方法論篇挑了三節講怎麼跟 AI 立規矩、長對話怎麼不跑偏，不寫程式碼也天天用得上。

「把 AI 用到專業」在會用的基礎上補兩塊：大模型原理整篇——知道它為什麼會編、邊界在哪，用起來才有判斷力；協作方法論整篇——四步流程、驗收標準、環境安全這套規矩，是讓 AI 穩定替你幹活的關鍵。再帶上程式設計基礎篇講詞表與向量的兩節，知識庫檢索為什麼會漏，你會有直覺。仍然跳過全部工程實現和產品設計的內容。

「做 AI 產品」在「用到專業」的基礎上補齊 Harness 全套、設計模式與評測，加上成本工程和自測中心。跟工程師對齊方案、判斷可行性、算成本，靠的就是這幾塊。跳過程式碼走查、長執行 Agent、安全容器化和三個硬核專題：動手實戰篇只保留產品視角的那部分（生圖的產品化清單、角色一致性、模型掛了怎麼辦），Agent Loop 和 MCP 的實現留給動手路線。

「自己動手搭」把全部正課吃下，包括動手實戰篇的完整程式碼走查和自我改進篇。建議全程跟著實戰主線走：每章末尾的「你現在能做什麼」按三檔任務做完，六個里程碑填滿，學完你手上就有一個真能幹活的 Agent 和一份自己的協作規範。三個原始碼專題不在這條路上，它們是讀別人的實現，不影響你自己搭。

「全都要」在動手路線之外多三個專題共 63 節。Grok Build 解剖帶你把一個生產級 Coding Agent 的 Rust 原始碼從入口讀到工具呼叫；DeepSeek Harness拆的是一切皆外掛的 TypeScript 底座；開源、蒸餾與本地部署講開源模型到底開了什麼、大模型怎麼變小、怎麼在自己機器上跑起來。這三塊難度最高，也最能拉開差距。
