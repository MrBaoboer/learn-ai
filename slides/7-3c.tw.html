📌 設計決策 ①
什麼資訊該存入長期記憶？使用者偏好、專案配置、歷史 Bug、常用操作，這些決定了 Agent 的個性化程度。
📌 設計決策 ②
記憶檢索品質取決於 Embedding 模型。「修登入介面」和「登入介面併發 500」，模型能匹配到同一條記憶嗎？
📌 設計決策 ③
記憶太多也是問題：topK=5 意味著每次最多召回 5 條。如何保證最重要的記憶排在最前面？
Takeaway
Takeaway　短期記憶（上下文視窗）讓 Agent 記住當前對話，長期記憶（向量檢索）讓 Agent 記住上個月的事。兩者配合，Agent 才能像真正的助手一樣：既瞭解你現在在做什麼，也記得你過去的偏好。
