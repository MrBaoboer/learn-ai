            模型推下一個 Token 時，當前上下文裏的每一個 Token 都在影響概率分佈。
            System Prompt 注入的約束詞，就是在上下文裏放入「高質素的前文」：
            它讓「我不確定」這個序列的概率上升，讓編造序列的概率下降。
            本質：用精心設計的前文，定向干預後文的概率分佈。
          

        

        

          
⚠ 侷限性：模型不知道自己不知道

          

            

              
約束指令有效的前提

              

                模型對某個問題有一定不確定感時，約束詞能把它推向承認不知道的序列。

                → 適合：問題超出知識範圍、模糊查詢、時效性資訊
              

            

            

            

              
約束指令失效的場景

              

                模型對某個錯誤答案高度自信時，它推出的第一候選詞就是錯的，約束詞干預不了這個概率。

                → 失效於：訓練數據裏的系統性錯誤、過時知識被當作事實
              

            

            

            

              
PM 應對策略

              

                對於「模型高度自信但可能出錯」的領域，Prompt 約束不夠，

                → 需要搭配 RAG（注入真實知識） 或 人工審核兜底
