腦暴：讓多個 AI 吵架

和人類開會一樣：一個人想到死不如多個人獨立思考再彙總。腦暴模式就是把同一個問題扔給多個 Agent，讓它們各自回答，最後由主持人整合共識與分歧。

一句話速覽

同一問題多角度獨立思考，彙總共識與分歧，這是羣體智慧的 AI 版

腦暴過程模擬
❓ 「如何提高用戶留存率？」
A
產品視角
B
數據視角
C
用戶視角
Agent A · 產品視角
優化新手引導流程，減少首日流失。增加個性化推薦，讓用戶更快找到價值。
Agent B · 數據視角
分析流失節點數據，第 3 天和第 7 天是關鍵。建議針對這兩個節點設計召回策略。
Agent C · 用戶視角
用戶回饋最多的是「不知道能幹什麼」。功能並不少，核心問題是價值傳遞不到位。

主持人彙總

三個 Agent 獨立思考後，主持人整合出：

共識：核心問題是價值傳遞，用戶沒感受到產品能幫他什麼
共識：新手引導是最高優先級改進點
⚡ 分歧：用數據驅動（B）還是用戶訪談驅動（C）來確定改進方向
⚡ 分歧：先做個性化推薦（A）還是先簡化核心流程（C）
點擊開始，觀察 3 個 Agent 獨立思考的過程
為什麼比一個 Agent 想到底更好

避免思維定式

一個 Agent 會沿着一條綫想下去。多個 Agent 從不同角色出發，天然產生不同視角。

發現盲區

Agent A 想不到的東西，Agent B 可能正好擅長。多角度覆蓋讓盲區更少。

⚖️ 分歧即價值

如果三個 Agent 意見一致，説明方向明確。如果有分歧，説明這個問題值得更深入討論。

⚡ 並行高效

三個 Agent 同時思考，總時間 = 最慢那個的時間，不會翻三倍。思考類任務天然可並行。

實踐要點：每個 Agent 必須獨立思考，不能看到其他 Agent 的答案。就像人類腦暴的規則：「先各自寫，再一起討論」。如果 Agent B 能看到 A 的答案，它會被帶偏，腦暴就失去意義了。
和人類開會一樣：多個獨立思考再彙總，比一個人想到死要好。腦暴模式的關鍵是獨立和彙總：每個 Agent 獨立回答，主持人負責提煉共識、標註分歧。
