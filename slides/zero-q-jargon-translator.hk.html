追問三連 · 當場問出底細

翻譯只是第一步。真想知道對方有幾斤幾兩，把下面三個問題記熟，哪個場合都能用。放心問，這三個問題很禮貌，只是答案藏不住。

🏗️

「模型底座是什麼？」

這個問題能問出他站在誰的肩膀上。用開源模型、接商業 API 都是正常操作，但答案決定了「自研」這個詞該打幾折。支支吾吾的，折扣自動加大。

📚

「訓練數據從哪來、花了多少算力？」

這個問題能問出他有沒有真的訓練過。真做過訓練的人，對數據規模和算力開銷如數家珍；沒做過的人，這兩個數字一個都答不上來。

🔌

「離開那家的 API，產品還能跑嗎？」

這個問題能問出產品的獨立性。答「能，換個底座就行」説明工程紮實；答「跑不了」也不丟人，但「核心技術全自研」的説法就該收回去了。

最後提醒一句：這套翻譯器的目的只是幫你聽懂，用來當場拆穿別人，飯局會變得很安靜。建議的用法是默默翻譯、禮貌追問，把判斷留在心裏。真話術不攻自破，真本事也藏不住。

✅ 這一頁想和你分享的

  • 聽宣傳抓三件事：模型底座、訓練數據、成本量級，三個都含糊的可以直接換台
  • 殼不丟人，吹牛才丟人：好產品大多是厚殼，要警惕的是薄殼配大詞
  • 口號不含資訊量：「深度賦能」「All in」這類詞，聽到時自動靜音即可
  • 追問三連隨身帶：底座、數據、獨立性，三個禮貌問題就夠用了
