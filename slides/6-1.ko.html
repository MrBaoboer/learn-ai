Prompt 엔지니어링

무엇이라고 말하든 모델은 그대로 됩니다

System Prompt에 역할을 지정하면 동일한 모델이 완전히 다른 어시스턴트가 됩니다. 역할극은 가장 기본적이면서도 효과적인 Prompt 기술입니다. 아래 역할과 형식을 클릭하여 출력이 어떻게 변하는지 확인해 보세요.

역할 선택 (System Prompt 전환)
같은 질문, 다른 역할
System Prompt (역할 정의)
👤 사용자 질문: 「요즘 스트레스가 많고 많이 지칩니다」
역할 답변 (같은 질문, 다른 역할)
출력 형식 제어
🎭 역할 = 시스템 프리셋. 모든 AI 프로덕트는 본질적으로 System Prompt 안에 서로 다른 역할 정의를 작성한 것입니다. 역할을 바꾸면 프로덕트가 바뀝니다.
