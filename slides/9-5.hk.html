體驗層
生成進度回饋
Alice 生圖時展示「畫緊…」的狀態動畫，用戶不會面對空白螢幕乾等。預估時間、進度指示讓等待可預期。
生成進度回饋
進度動畫 + 預計時間，不讓用戶乾等
失敗重試機制
模型失敗後一鍵重試，不用重新描述需求
結果預覽與選擇
一次出多張供選擇，支持放大預覽
歷史記錄
之前的圖能回看、重用、對比
質素層
參考圖 + Prompt 優化 = 穩定高質素
角色參考圖保證一致性，LLM 翻譯優化保證每次 Prompt 都是生圖模型最理解的格式。雙重保障。
Prompt 優化（LLM 翻譯）
用戶講人話，LLM 翻譯成模型最佳輸入
角色一致性
參考圖錨定，多場景中角色外貌穩定
尺寸適配
頭像/聊天配圖/朋友圈寬圖，自動適配不同尺寸
質素兜底
檢測並過濾明顯質素差的結果（模糊、變形）
工程層
模型會掛、會慢、會貴，都得處理
降級鏈保證可用性，超時策略保證體驗，成本控制保證不虧錢。這三件事缺一不可。
模型降級鏈
主模型掛了自動切備選，保證服務不中斷
超時與重試
合理超時閾值 + 自動重試 N 次再放棄
成本控制
按用戶/時段限額，監控異常調用，防止成本爆炸
結果持久化
圖片存 CDN，不丟失、能溯源、支持回看
安全層
生圖涉及內容安全和隱私
用戶上傳的參考圖不能洩露，生成結果不能違規，權限邊界要清晰透明。
輸入內容審核
過濾違規 Prompt，攔截敏感/違法描述
輸出內容審核
即使 Prompt 沒問題，生成結果也要過審
版權風險控制
避免生成與已有作品高度相似的圖片
隱私保護
用戶參考圖不洩露、不訓練，存儲策略透明
調通 API 只是 10%，剩下 90% 是產品化。Alice 的生圖功能從能調通到能上綫，花了三個月做這些事。這張清單不只適用於生圖。任何 AI 功能從 Demo 走向 Production，都需要在體驗、質素、工程、安全四個維度做到位。
