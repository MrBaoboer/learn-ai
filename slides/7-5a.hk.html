📌 Skill 本質是經驗封裝：把高級工程師的操作流程寫成 Agent 能理解的手冊。Agent 不再每次從零摸索，而是站在前人肩膀上執行。
📌 效率差距可達 3 倍以上：沒有 Skill 時 Agent 靠通用能力摸索，有 Skill 時按最佳實踐執行。Token 消耗差 3.75 倍，錯誤從 3 個變 0 個。
📌 產品經理要回答的問題：為哪些高頻操作預裝 Skill？允許用戶自建 Skill 嗎？Skill 之間衝突了怎麼辦？誰來維護和更新 Skill？
Takeaway
Takeaway　Skill 把「摸索」變成「執行」。同一個發版任務，沒有 Skill 時 Agent 試錯 12 輪花 1.5 萬 Token 還出 3 個錯；有 Skill 時 5 輪搞定只花 4000 Token 零錯誤。Skill 是 Agent 的經驗傳承機制。
