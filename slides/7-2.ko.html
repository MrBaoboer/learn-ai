Agent 엔지니어링

도구 호출의 비밀

모델은 실제로 코드를 실행하지 않습니다. 단지 구조화된 텍스트를 출력할 뿐이며, 프레임워크 코드가 이를 파싱하고 실행합니다. 스크롤을 내리면 완전한 호출 체인이 자동으로 추적됩니다.

1
System Prompt
모델에게 어떤 도구를 사용할 수 있는지 알립니다
2
사용자 질문
사용자가 요청을 보냅니다
3
모델이 JSON 출력
텍스트 예측일 뿐 — 실제 호출이 아닙니다!
4
프레임워크 파싱 + 실행
여러분이 작성한 코드가 진짜 실행자입니다
5
결과를 컨텍스트에 주입
tool_result 추가, 모델 계속 예측
6
최종 답변
모델이 사용자가 읽을 수 있는 응답을 생성합니다
핵심: 모델은 항상 텍스트를 예측할 뿐입니다.
도구 호출 = 텍스트 → 코드 파싱 → API → 텍스트
MESSAGE LIST · 실시간 추적
여기까지 스크롤하면 자동 재생됩니다
