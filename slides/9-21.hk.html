Prompt Harness

Skill：可運營的 Prompt 模組

System Prompt 管我係邊個，Tool 管我可以做到啲咩，咁 Skill 管咩？佢管嘅係遇到某件事，點樣一步一步做好。檔案即配置，版本可追溯。

一句話速覽

檔案即配置、版本可追溯，讓 Prompt 也能像程式碼一樣管理

三者對比

System Prompt

全局身份
定義 AI 係邊個：名字、性格、基本原則。係所有對話嘅底色。
作用範圍全局
修改頻率很少
生命週期整個產品

Tool

能力註冊
話俾 AI 知有咩工具可以用：名字、參數、功能。係能力嘅菜單。
作用範圍單次調用
修改頻率中等
生命週期功能迭代

Skill

流程指引
一個完整的任務執行方案：什麼時候觸發、用哪些工具、按什麼步驟來。
作用範圍特定任務
修改頻率高頻迭代
生命週期獨立版本
一個 Skill 的結構

點擊每個區塊展開説明

content-creator.skill

觸發條件 幾時啓用這個 Skill
當用戶講「幫我寫篇文章」「我想寫」「準備寫」等觸發詞時，AI 自動載入這個 Skill 來指導後續行為。唔係每次對話都載入，只喺匹配時注入。
允許的工具列表 這個任務能用哪些工具
明確列出執行這個 Skill 時允許使用的工具。比如內容創作可能允許 web_search、note_read，但不允許 file_delete。通過白名單控制風險。
執行流程 一步一步點樣做
描述從頭到尾的執行步驟：先確認需求 → 蒐集素材 → 列大綱 → 逐段寫作 → 整體潤色 → 交付。每一步可以有分支和條件判斷。
輸出格式要求 最終產出係點樣
規定最終輸出的格式、長度、風格。比如：標題不超過 20 字、分段清晰、口語化表達、結尾有行動建議。確保每次產出質素一致。
Skill 的生命週期
1
編寫
一個檔案，純文本
2
註冊
放到指定目錄即生效
3
觸發
匹配條件時自動載入
4
迭代
改檔案 = 改行為，Git 追溯
點解唔直接寫喺 System Prompt 裏？
System Prompt 是全局的，改了影響所有場景。Skill 是按需載入的，只在特定場景注入，不會污染其他任務的行為。而且 Skill 檔案可以獨立版本管理：邊個改咗咩、幾時改嘅，一目了然。
Prompt 也需要可複用、可迭代、可追溯，Skill 就是 Prompt 的模組化。像管理程式碼一樣管理 AI 的行為指引，每個任務一個檔案，改了就生效。
