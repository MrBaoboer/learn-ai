멀티 Agent 협업: 혼자 다 못 하면 팀을 꾸려라

메인 Agent가 작업 분해 → 서브 Agent가 각자 역할 담당 → 결과 집계 및 전달. 읽기 전용 작업은 병렬로 가속하고, 쓰기 작업은 직렬로 안전하게.

프로덕트 결정
Takeaway 복잡한 작업은 Agent 하나가 억지로 감당하는 게 아니라 전문 서브 Agent 여러 개로 분해합니다: 리서처가 코드를 읽고, 개발자가 코드를 수정하고, 테스터가 검증합니다. 읽기 전용 작업은 병렬로 가속하고, 쓰기 작업은 직렬로 안전하게. 이것이 Agent 세계의 팀 협업입니다.
