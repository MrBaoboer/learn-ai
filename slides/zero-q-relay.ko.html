API 중계 사이트가 뭔가요? 왜 별로 추천하지 않을까요?

AI 도구를 만지작거리기 시작하면 조만간 이런 광고를 보게 될 거예요: 「GPT / Claude API 70% 할인, 구매 즉시 사용」. 이런 곳을 「중계 사이트」라고 불러요. 먼저 분명히 해 둘게요: 판매자가 다 나쁜 사람이라는 게 아니에요 — 다만 이 구조 자체에, 미리 알아 둘 가치가 있는 리스크가 몇 가지 있어요.

한 줄 답변

중계 사이트는 여러분과 AI 공식 사이에 낀 「되팔이 상인」이에요: 인터페이스를 대량으로 확보해 여러분에게 되팔죠. 싼 건 사실이지만, 여러분의 모든 말이 먼저 그들의 서버를 거쳐야 하고, 모델이 정품인지, 내일도 살아 있을지는 전부 그들의 양심에만 달려 있어요.

👀

여러분의 내용이 그들에게 완전히 투명해요

여러분이 보낸 계약서, 이력서, 회사 데이터, 사적인 질문이 전부 원문 그대로 중계 사이트의 서버를 거쳐요. 저장하는지, 들여다보는지, 파는지 — 여러분은 검증할 방법이 없어요. 공식 대기업은 개인정보 협약과 규제의 구속을 받지만, 중계 사이트는 운영 주체가 누구인지조차 알 수 없는 경우가 많아요.

🎭

모델이 「몰래 바꿔치기」될 수 있어요

플래그십 모델을 쓰고 있다고 생각했는데, 뒤에서 몇 배나 저렴한 경량 모델로 바꿔서 차익을 챙길 수 있어요 — 답변이 멍청해져도 여러분은 프롬프트를 잘못 쓴 탓이라고 생각하겠죠. 커뮤니티에 이런 「섞어 팔기」 검증 사례가 심심찮게 올라오는데, 일반 사용자는 거의 분별할 수 없어요.

🏃

충전 잔액이 하룻밤에 0이 될 수 있어요

저가는 대개 지속 불가능한 출처(대량 가입, 도용 결제, 회색 경로)에서 나와요. 업스트림에서 계정이 정지되거나 운영자가 사이트를 닫으면, 충전한 돈을 돌려받을 곳이 어디에도 없어요. 이 바닥에서 「먹튀」는 드문 일이 아니에요.

그럼 올바른 길은 뭘까요? 일반 사용자라면: 공식 앱(Doubao, Kimi, Qwen, ChatGPT 등)을 바로 쓰세요. 무료 사용량이 일상 용도로 충분해요. 개발자라면: 공식 API나 대기업 클라우드 플랫폼(볼케이노 아크, 알리클라우드 바이롄, 마이크로소프트 Azure 등)을 이용하세요 — 중국 모델의 공식 가격은 원래 저렴해서, DeepSeek은 100만 자에 1~2위안이라 아낄 수 있는 차액이 정말 얼마 없어요.

✅ 이 페이지에서 나누고 싶은 것

  • 중계 사이트 = 되팔이 상인: 여러분의 모든 말이 먼저 그들의 서버를 거쳐요
  • 세 가지 구조적 리스크: 내용 노출, 모델 바꿔치기 가능성, 잔액 소멸 가능성
  • 판매자의 인성과 무관해요: 「검증할 수 없는 중간자를 한 층 더 두는 것」의 필연적 대가예요
  • 올바른 길은 비싸지 않아요: 공식 앱은 무료, 중국 공식 API는 원래 저렴해요
