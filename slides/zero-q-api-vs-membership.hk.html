零基礎入門 · 小白三千問

API 是什麼？和開會員有什麼區別？

總看到有人説「充 key」「調 API」，聽着像圈內黑話。其實它和你每月訂的會員一樣，都是在給 AI 付錢，只是兩種完全不同的付錢方式。這一頁用一個買菜的類比講明白。

一句話回答

會員是包月自助餐，在人家店裏隨便吃；API 是按克稱重的散稱食材，買回去自己開火做菜。普通人開會員就夠了，接工具、做產品的人才需要 API。

先記住類比 · 自助餐與散稱食材
🍱

會員 = 包月自助餐

交一次月費，在官方 App 裏隨便聊。菜是人家做好端上桌的：介面、聊天記錄、聯網搜索都配齊了，你只管張嘴吃。限制也很像自助餐：只能在店裏吃，沒法打包帶走給別的軟件用，吃太猛還會被提示「歇一會兒」。

🥬

API = 按克稱重的散稱食材

按實際用量付錢，用多少稱多少。買回來的是生食材：一個接口地址加一把鑰匙（key），得自己接進程式或工具裏才做得成菜。自由度大，可以隨便折騰，代價是你得會「開火」。

拖一拖 · 你的用量適合哪種付法

兩種付法誰更划算，答案隨用量變化。下圖裏橫的藍綫是會員（月費固定，吃多吃少一個價），爬坡的橙綫是 API（按量計費，用得越多花得越多）。拖動滑塊，看看兩條綫的高低怎麼換位。金額只是示意刻度，各家定價不同，看趨勢就好。

會員 · 固定月費 API · 按量計費
輕度 · 聊幾句中度 · 處理文檔重度 · 批量跑任務
為什麼有人要「充 key」

你在教程裏看到的「充 key」，幾乎都發生在同一個場景：某個第三方工具要用 AI 的能力。翻譯插件、寫作軟件、自動化腳本，這些工具自己沒有 AI，得由你遞給它一把鑰匙，它拿着鑰匙去調用模型，費用記在你的帳上。這把鑰匙，就是 API key。

key 説白了就是一串密碼

誰拿到這串字符，誰就能用你的額度、花你的錢。別把 key 發到羣裏、貼到帖子裏、存進公開的在綫文檔。萬一洩露了，第一時間去官網把它作廢，再重新生成一把。

買 key 的安全提醒

買 key 認準官方渠道：模型廠商的官網，或者大廠雲平台。網上那些「三折 key」「無限額度卡」大多來自中轉站或灰色渠道，便宜的代價可能是對話被別人看光、餘額一夜清零。想了解這裏面的門道，可以看API 中轉站為什麼不太推薦那一頁。

還沒確定要走哪條路？記住一個簡單分法：你只是想用 AI 聊天干活，開會員；你要讓某個軟件或程式替你調 AI，才需要 API。多數人一輩子只需要前者。

  • 普通人開會員就夠了：省事、配套全，接工具做產品的人才需要 API
