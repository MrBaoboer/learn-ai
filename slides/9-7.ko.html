Agent 실전

Agent이 무한 루프에 빠지는 이유

실험실에서의 Agent 무한 루프는 쉽게 발견됩니다: 콘솔을 한 번만 봐도 알 수 있습니다. 하지만 프로덕션 환경에서의 오류는 훨씬 더 은밀합니다. 사용자는 "Agent이 루프에 빠졌어요"라고 말하지 않습니다. 그들은 "AI가 왜 이렇게 느려요?" 또는 "고장난 거 아닌가요?"라고 할 것입니다.

프로덕션 환경에만 나타나는 네 가지 장애 패턴
동일 파라미터 루프
Agent이 완전히 동일한 파라미터로 같은 도구를 연속 3번 호출합니다
클릭하여 상세 보기

모델이 이전에 이미 이 작업을 수행했다는 것을 잊었거나, 이전에 성공하지 못했다고 판단하여 재시도합니다. 하지만 파라미터가 동일하면 결과도 항상 동일합니다.

사용자가 경험하는 것
"한참 돌아가는데 아무 반응이 없어요" · "왜 계속 로딩 중인가요?"

전형적인 시나리오: 같은 파일 반복 읽기, 같은 키워드 반복 검색, 같은 API 반복 호출

수익 체감
50번의 루프를 실행했지만 가치 있는 결과물이 거의 없습니다
클릭하여 상세 보기

Agent은 바쁘게 움직이지만, 매 반복마다 주변적인 작업만 합니다: 형식 정리, 반복 확인, 무관한 검색. 일하는 것처럼 보이지만 실제로는 핵심 목표를 진행시키지 못합니다.

사용자가 경험하는 것
"2분 기다렸는데 겨우 이게 다인가요?" · "AI가 대충 하는 거 아닌가요?"

전형적인 시나리오: Agent이 복잡한 작업에서 방향을 잃고 안전하지만 쓸모없는 소소한 동작을 반복합니다

텍스트 반복
모델이 자신이 한 말을 반복하기 시작하고, 같은 내용이 계속 나타납니다
클릭하여 상세 보기

컨텍스트가 너무 길거나 모델이 혼란스러울 때, 반복 모드로 저하됩니다: 이전 출력을 다시 생성합니다. 모델이 멈춘 게 아니라 길을 잃은 것입니다.

사용자가 경험하는 것
"같은 말을 계속 하고 있어요" · "왜 또 이 내용이 나와요?"

전형적인 시나리오: 긴 대화의 후반부, 컨텍스트가 윈도우 한계에 근접, 작업 설명이 모호한 경우

도구 연속 실패 연쇄
도구 하나가 실패하고, Agent이 미친 듯이 재시도하여 전체 체인을 망가뜨립니다
클릭하여 상세 보기

사용자가 경험하는 것
