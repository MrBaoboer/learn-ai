클라우드 LLM은 여러 GPU 노드에서 실행되며, 각 요청은 무작위로 라우팅됩니다. 노드 A에는 캐시가 있지만 노드 B/C에는 없습니다. 히트 여부는 운에 달려 있으며, 실제 히트율은 <30%입니다.

✅ 명시적 캐시: 앵커 포인트를 직접 지정

API 요청에 cache_control 한 줄을 추가하면, 플랫폼이 캐시가 있는 노드로 요청을 라우팅하는 것을 보장합니다. 무작위 라우팅에 의존하지 않으며, 히트율은 100%에 가깝습니다.
