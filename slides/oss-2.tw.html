開源專題 · 開源到底開的是什麼

真開源 vs 假開源：怎麼看懂一張許可證

幾乎每家都說自己「開源」，但這個詞在各家嘴裡的含義差得很遠。有的能隨便商用，有的使用者量一大就要另外簽合同，有的只是發了篇論文。學會自己判斷，比記住誰家開源更有用。

一句話速覽

三個問題定位開放程度；用同一套尺子橫量 Qwen、Mistral、DeepSeek、Llama 與只給 API 的模型

三個問題，問完就有答案

不用讀完整份許可證。按順序問下面三個問題，絕大多數模型的開放程度就定位清楚了。

問題 1權重檔案能下載嗎？

能下載，才談得上後面所有事情。只能透過 API 呼叫的模型，無論宣傳裡怎麼寫，你都拿不到上一節說的那個控制權。這一問就能篩掉一大半。

問題 2能商用嗎？有沒有附加門檻？

這裡最容易踩坑。有的許可證允許商用，但加了使用者規模上限；有的限定只能用於研究。做產品之前不看清楚，等使用者量漲上來才發現要補授權，就很被動了。

問題 3能用它的輸出去訓練新模型嗎？

也就是能不能拿它做蒸餾。這一條決定了你能否在它基礎上做出自己的模型，是後面兩節要展開講的事情。各家在這一條上的態度分歧最大。

光看不算掌握，拿一個你手上正在考慮的模型來走一遍。下面這個嚮導就是上面三問，一次問一個，答完直接告訴你它落在哪一檔。

收進三個檔次
第一檔 · 權重開放且無附加條件
用的是 Apache 2.0、MIT 這類標準開源許可。下載、修改、商用、再分發、拿去訓練新模型都不需要額外打招呼，也沒有使用者量門檻。法務審起來最省事。
代表：Qwen3 全系、Mistral 7B、DeepSeek-R1
第二檔 · 權重開放但附帶自訂條款
廠商自己寫的許可證，通常在商用規模、使用場景或署名義務上加限制。技術上完全可用，商業上要先算清楚自己會不會撞到紅線。
代表：Llama 3 系列
第三檔 · 只提供 API
拿不到權重，也就沒有本地部署、私有化和繼續訓練這些選項。能力可能是最強的，但你租的是使用權。
代表：GPT-4、Claude、Gemini Ultra
一個必須說清楚的事實
上面五家，訓練資料全都沒有公開。按傳統軟體的開源標準，原始碼等價物應該是訓練資料加訓練程式碼，光給編譯產物不算開源。大模型領域裡說的開源，實際指的是權重開放。這是一個被行業預設接受的降級定義，用這個詞的時候心裡要清楚它的邊界。

同樣值得留意的是，許可證會變。Qwen 在 2.5 那一代用的是分級許可，多數尺寸走 Apache 2.0，3B 和 72B 另有單獨條款；到 Qwen3 才統一成全系 Apache 2.0。選型時看的應該是你要用的那個具體版本的許可證，不是這家公司的整體印象。

Qwen2.5 系列多數尺寸採用 Apache 2.0，其中 3B 採用 Qwen Research 許可、72B 採用 Qwen 許可；Qwen3 系列八款模型統一採用 Apache 2.0。來源：Qwen 官方釋出說明。
帶走這張自查清單

下次評估一個模型時，按順序走一遍：

一、去官方倉庫找許可證檔案本身，不看新聞稿和宣傳頁。
二、確認你要用的那個具體尺寸的許可證，同一系列內可能不一致。
三、如果是自訂許可證，重點找使用者規模、使用場景、地域這三類限制。
四、確認能否用於訓練，這決定了你之後有沒有微調和蒸餾的空間。
