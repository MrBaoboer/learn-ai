제품화 체크리스트 (차원별 펼치기)
완성도
0/16
경험 레이어
생성 진행 피드백
Alice는 이미지 생성 중 "그리는 중..." 상태 애니메이션을 표시하여 사용자가 빈 화면을 기다리지 않습니다. 예상 시간과 진행 표시로 기다림을 예측 가능하게 합니다.
생성 진행 피드백
진행 애니메이션 + 예상 시간 — 빈 화면 대기 없음
실패 재시도 메커니즘
모델 실패 후 원클릭 재시도, 요청 재설명 불필요
결과 미리보기 및 선택
한 번에 여러 장 생성하여 선택, 확대 미리보기 지원
히스토리
이전 이미지 다시 보기, 재사용, 비교 가능
품질 레이어
참조 이미지 + Prompt 최적화 = 안정적 고품질
캐릭터 참조 이미지로 일관성을 보장하고, LLM 번역 최적화로 매번 Prompt가 이미지 모델이 가장 잘 이해하는 형식이 되도록 합니다. 이중 보장.
Prompt 최적화 (LLM 번역)
사용자가 자연스럽게 말하면 LLM이 모델 최적 입력으로 번역
캐릭터 일관성
참조 이미지 앵커링으로 여러 씬에서 캐릭터 외모 안정
크기 적응
아바타/채팅 이미지/소셜 와이드 이미지 — 다양한 크기 자동 적응
품질 보정
명백히 품질 낮은 결과 감지 및 필터링 (흐림, 변형)
엔지니어링 레이어
모델은 다운될 수 있고, 느려질 수 있고, 비쌀 수 있습니다 — 모두 처리해야 합니다
폴백 체인으로 가용성 보장, 타임아웃 정책으로 경험 보호, 비용 제어로 손실 방지. 세 가지 모두 필수입니다.
모델 폴백 체인
기본 모델 다운 시 자동으로 백업으로 전환, 서비스 중단 없음
타임아웃 및 재시도
적절한 타임아웃 임계값 + N회 자동 재시도 후 포기
비용 제어
사용자/시간대별 할당량, 비정상 호출 모니터링, 비용 폭발 방지
결과 영속화
이미지 CDN 저장 — 손실 없음, 추적 가능, 다시 보기 지원
안전 레이어
이미지 생성은 콘텐츠 안전과 개인정보를 포함합니다
사용자가 업로드한 참조 이미지는 유출되어서는 안 되고, 생성 결과는 규정을 준수해야 하며, 권한 경계는 명확하고 투명해야 합니다.
입력 콘텐츠 심사
규정 위반 Prompt 필터링, 민감/불법 설명 차단
출력 콘텐츠 심사
Prompt가 문제없더라도 생성 결과도 심사 통과 필요
저작권 위험 제어
기존 작품과 매우 유사한 이미지 생성 방지
개인정보 보호
사용자 참조 이미지 유출 금지, 훈련 금지, 저장 정책 투명
API 연결은 10%에 불과하고 나머지 90%가 제품화입니다. Alice의 이미지 생성 기능은 API 연결에서 프로덕션 출시까지 3개월이 걸렸습니다. 이 체크리스트는 이미지 생성에만 해당하지 않습니다. Demo에서 Production으로 가는 모든 AI 기능은 경험, 품질, 엔지니어링, 안전 네 가지 차원을 모두 갖추어야 합니다.
