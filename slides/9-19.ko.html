Prompt Harness

System Prompt는 텍스트 덩어리가 아닙니다

프로덕션급 System Prompt는 생각나는 대로 쓰는 게 아닙니다. 계층적으로 관리됩니다：신원 레이어, 환경 레이어, 도구 레이어, 행동 레이어 — 각각의 역할이 있어 한 레이어를 변경해도 다른 레이어에 영향을 주지 않습니다.

「텍스트 덩어리」는 어떻게 생겼나요

흔한 혼란스러운 작성 방식

당신은 Alice라는 이름의 AI 어시스턴트입니다。웹을 검색하고 파일을 읽고 쓸 수 있습니다、 지금은 2026년이며 사용자는 한국에 있습니다。사용자가 검색을 요청하면 web_search 도구를 사용하세요、 답변 전에 먼저 생각하고 정보를 지어내지 마세요。당신의 성격은 따뜻하고 친절합니다、 파일 작업에는 file_read와 file_write를 사용하세요、사용자의 언어 선호도는 한국어입니다、 확신이 없으면 모른다고 말하세요...
신원, 환경, 도구, 행동이 모두 뒤섞여 있습니다. 한 곳을 변경하면 모든 것에 영향을 줄 수 있으며, 어느 부분이 어떤 행동에 영향을 미치는지 아무도 말할 수 없습니다.
계층 관리：네 레이어, 각각의 역할

각 레이어를 클릭하여 담당 역할을 확인하세요

신원

신원 레이어

나는 누구인가？성격, 역할, 기본 페르소나

AI의 정체성을 정의합니다：
  • 이름, 역할 정의
  • 성격 특성(친절 / 엄격 / 유머…)
  • 기본 능력 경계(할 수 있는 것, 할 수 없는 것)
특성：거의 변하지 않으며 한번 정해지면 거의 수정하지 않습니다.
환경

환경 레이어

현재 상황은？시스템 상태, 사용자 컨텍스트

현재 런타임 정보를 제공합니다：
  • 사용자 기본 정보(언어 선호도, 시간대…)
  • 현재 OS, 앱 상태
  • 세션 컨텍스트(어떤 페이지, 이전에 무엇을 했는지)
특성：세션마다 다를 수 있지만 같은 세션 내에서는 비교적 안정적입니다.
도구

도구 레이어

무엇을 사용할 수 있나？사용 가능한 도구와 API

AI가 사용할 수 있는 도구를 등록합니다：
  • 도구 이름과 기능 설명
  • 파라미터 형식
  • 사용 제한 및 주의사항
특성：기능 반복 개발에 따라 추가/삭제되며 변경 빈도가 중간 정도입니다.
행동

행동 레이어

어떻게 행동하나？출력 형식, 의사결정 규칙

AI의 행동 전략을 규정합니다：
  • 답변 스타일과 형식 요구사항
  • 의사결정 우선순위(먼저 할 것, 나중에 할 것)
  • 안전 가드레일(해서는 안 되는 것, 확인이 필요한 것)
특성：제품 반복 개발에서 가장 자주 변경되는 부분 — 규칙 하나를 바꾸면 AI 행동이 달라집니다.
계층화의 장점

한 레이어 변경이 다른 레이어에 영향 없음

새 도구 추가？도구 레이어만 수정. 답변 스타일 조정？행동 레이어만 변경. 연쇄 효과 없음.

다인 협업 시 충돌 없음

프로덕트가 행동을 수정하고, 엔지니어가 도구를 추가하고, 운영이 페르소나를 조정 — 각자 자신의 파일을 수정하므로 Git 병합 충돌이 없습니다.

더 정확한 A/B 테스트

다른 답변 전략을 테스트하고 싶으신가요？행동 레이어만 교체하고 나머지 세 레이어는 그대로 유지하면 변수가 하나로 격리됩니다.

문제 해결이 더 쉬움

AI 행동이 이상한가요？레이어별로 확인：신원이 잘못됐나？환경 정보가 오래됐나？도구 설명이 틀렸나？규칙 충돌인가？

텍스트 덩어리에서는 한 곳을 변경하면 모든 것에 영향을 줄 수 있습니다. 계층 관리를 하면 한 레이어를 변경해도 다른 레이어에 영향을 주지 않습니다.프로덕션급 System Prompt는 네 개의 독립적으로 관리되는 모듈입니다.
