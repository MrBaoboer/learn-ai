CHAPTER 12 · CALL PATH

從真實 main() 到第一輪採樣

實際入口位於 xai-grok-pager-bin/src/main.rs。同一個組合入口解析命令與交互模式，再把工作交給 TUI 或 Shell Agent 宿主。

一句話速覽

追蹤入口、會話創建、提示詞渲染、模型採樣與流式返回的完整調用鏈

課程目標
能準確説出四種運行分支，並沿 connect_or_spawn、MvpAgent、spawn_session_on_thread、SessionActor、SamplerActor 定位第一輪對話。
核心視覺 · 教學化調用圖
run_headless

Agent 無頭模式

grok agent headless 進入 Shell 提供的無頭宿主。

run_stdio_agent

Stdio Agent

通過 ACP stdio 收發請求，適合外部客户端驅動。

run_leader

Leader 進程

承載長生命週期 Agent，並通過連接通道服務客户端。

app::run

交互 TUI

預設交互分支進入 pager 應用，TUI 可經 leader 建立連接。

主軸交接
connect_or_spawn建立 leader 連接或按需啓動進程。
MvpAgent響應 ACP 請求並管理會話句柄。
spawn_session_on_thread為 Session 創建 OS 綫程。
SessionActor推進 turn loop，協調狀態和工具。
SamplerActor為請求創建流式採樣任務。

  let rt = tokio::runtime::Builder
